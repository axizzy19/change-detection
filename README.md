# Change Detection на спутниковых снимках (LEVIR-CD)

## Описание проекта

Данный проект посвящён задаче обнаружения изменений на спутниковых изображениях.
Модель получает на вход два снимка одной и той же местности, сделанные в разное время, и предсказывает маску изменений — области, где произошли изменения (например, появление или исчезновение зданий).

## Цель проекта

Целью проекта является:

* Построение модели компьютерного зрения для выявления изменений на изображениях
* Изучение архитектур типа Siamese U-Net
* Практическое освоение пайплайна обучения нейросетей

## Используемый датасет

Датасет: https://www.kaggle.com/datasets/mdrifaturrahman33/levir-cd-change-detection
Используется датасет **LEVIR-CD**, содержащий:

* `A/` — изображения местности в момент времени T1
* `B/` — изображения той же местности в момент времени T2
* `label/` — бинарные маски изменений

## Технологии

В проекте использованы:

* Python
* PyTorch
* NumPy
* Matplotlib
* tqdm

## Архитектура модели

Используется Siamese U-Net:

* Два входных изображения (A и B)
* Общий encoder
* Вычисляется разница признаков
* Decoder восстанавливает карту изменений

Особенности:

* Использование skip-connections
* Binary segmentation

## Этапы выполнения работы

### 1. Подготовка окружения

* Установка Python и зависимостей
* Настройка WSL
* Запуск Jupyter Notebook

### 2. Загрузка и организация данных

* Скачивание датасета с Kaggle
* Организация структуры папок
* Формирование списков путей к изображениям

### 3. Создание Dataset и DataLoader

* Загрузка изображений A, B и mask
* Нормализация данных
* Объединение изображений в 6-канальный тензор
* Подготовка батчей

### 4. Реализация модели

* Encoder-блоки
* Decoder-блоки
* Siamese архитектура
* Финальный слой для бинарной сегментации

### 5. Обучение модели

* Использование функции потерь: `BCEWithLogitsLoss`
* Оптимизатор: Adam
* Обучение на GPU (CUDA)
* Отображение прогресса через tqdm

### 6. Сохранение модели

* Сохранение весов в файл `.pth`
* Возможность продолжения обучения

### 7. Визуализация результатов

* Отображение:

  * Image A
  * Image B
  * Предсказанная маска изменений
* Проверка качества модели

## Результаты

На начальных этапах:

* Модель начинает улавливать базовые изменения
* Требуется больше эпох для улучшения качества
